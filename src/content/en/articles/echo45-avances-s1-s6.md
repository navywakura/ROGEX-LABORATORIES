# ECHO-4.5 moves on: a world model, our own game simulator and ECHO asking a language model for help

26 September 2026 · In development · ECHO-4.5 · ARC-AGI-3 · ARC Prize 2026

This morning we reported that [ECHO-4.5 was in development](/en/articulos/echo45-en-desarrollo),
with S4 red. Since then:
- **S4 has turned green** on the development games;
- we have built **our own game simulator (S5)**, which found faults that our test games were hiding,
  and put it through an exam;
- ECHO has learned to **push boxes and understand click games**;
- **S6** has started, in which ECHO writes its own requests to a language model to improve itself.

**We will publish the S6 results in about 12 hours.**

## S4: what the best agents do, without a language model

We studied how the best systems score so well on ARC-AGI-3. Almost all of them follow the same
pattern:
- an **executable world model**;
- every hypothesis is **checked by replaying what has already been seen**;
- **simple rules** are preferred;
- they **plan inside the model** before spending actions in the game.

ECHO was already, above all, a verifier, so we adopted this without a language model:
- before every key press it **predicts** whether it will move, and checks;
- it learns walls as **colours**, one rule instead of a thousand cases;
- it **explores inside its model** instead of bumping into walls.

In the game g50t it went from winning a level **by luck** (1 attempt in 3, after more than 1800
actions) to winning it with **all 3 seeds**. In one of them it took **61 actions**, where the human
reference is 78.

## S5: a simulator so we do not fool ourselves

We only have 8 development games, and it is very easy to fit an agent to them without noticing. So
we built **ARC3-GYM**:
- **games generated by code**, with the same interface as ARC-AGI-3;
- **seven mechanics**: maze, switch, lever, box, lights, arrows and mixed;
- **random colours**, so rules have to be learned, not memorised;
- **an exact solver** that guarantees every level has a solution and gives the minimum number of
  actions.

Under its original contract **S5 came out red**, and we published that too:
- the first version was too easy: random play completed 27 % of the levels;
- the S4 agent **did not generalise**: it completed fewer levels than the previous one.

The simulator found two faults that our 8 games were hiding:
1. **ECHO took the floor for its body.** When it moves, the hole it leaves shifts the floor's
   centre. Now "me" has to move **rigidly**.
2. **It read the goal from the wrong level** and ended up chasing the floor.

Later, while working on causes (stepping on a switch, using a lever), a third fault appeared: when a
level restarted, the body's jump back to the start **taught it that walls could be walked through**.

Everything was fixed looking **only** at the simulator's training games. To know whether the fix was
real, we ran a **frozen exam (S5-D)**: 100 new games, the code sealed with fingerprints, and a single
measurement.

| On 100 new games (S5-D) | Levels (3 seeds) | Official score |
|---|---|---|
| Random | 47 (3.1 %) | 0.002 |
| v3 | 940 | 0.66 |
| **v5.2** | **1103 (+17 %)** | **7.42** |

**S5 is green by exam.**

## Boxes and click games

After the exam we added three abilities, developed only on the simulator's training games:
- **Pushing:** if an object moves with me when I walk into it, it is "pushable", and ECHO plans in its
  model how to take it where it belongs. On boxes it goes from 0.6 to **4.5 levels out of 5**.
- **Clicks that act as keys:** if clicking something still always moves another thing the same way,
  that click is a key, and the whole body model is used. On arrows it often reaches **the exact
  minimum number of actions**.
- **A model of what each click changes:** it learns which lights each click changes, and after
  winning a level it plans the next ones.

The resulting agent, **v5.6**, completes 805 levels out of 900 on the simulator's test games, against
681 for v5.2 and 600 for v3 (chart above). On the real development games, without tuning anything on
them, it rises from 0.960 to **1.03**.
- We **dropped** a fourth idea, using the body model in mixed games too. It improved the simulator
  but **made two real games worse**.
- v5.6 has not yet passed a frozen exam like S5-D.

## Kaggle: ARC Prize 2026

The `echo-arc` package with v5.2 runs without errors in the competition environment. On the 25 public
games it averages **0.73 out of 100**, against 0.21 for the first version we submitted.
- That is still **very little** next to the best systems.
- Those 25 games include the 16 of ECHO-4.5's final exam. **We tuned nothing on them**, but we
  declare it: we have seen that aggregate result.

## S6: ECHO asks for help and decides what to accept

Until now, the language model solved and ECHO watched over it. In S6 it is the other way round:
**ECHO uses the model as a tool to improve itself**. At each step:
1. ECHO looks at which tasks it fails and which it nearly gets.
2. **It writes the request itself**, with four possible types, and learns which ones work for it.
3. The model proposes a **new operation**.
4. ECHO accepts it only if:
   - its code is safe;
   - it solves tasks that were not solved before;
   - it does not make others worse.

The model can **never** touch the verifier, the sealed evaluations or the criteria: a fingerprint
check voids the campaign if anything changes. We saw it work: a test run voided itself when we edited
the contract while it was running.

The model is **Qwen2.5-Coder 7B**, on Kaggle's free GPUs: cost $0. We will compare four arms:
- **the seed** alone, which gives 24 held-out tasks;
- **a fixed request**, always the same (300 proposals);
- **ECHO's requests** (300 proposals);
- **ECHO's same proposals, without verification**.

It will be green if:
- ECHO reaches 27 held-out tasks or more;
- its requests beat the fixed request;
- it learns to ask better over time;
- verifying beats not verifying.

**We will give the results in about 12 hours**, green or red.

## What we do not claim

- That ECHO "understands" like a person.
- That it will win ARC Prize. We start very low.
- That the simulator replaces the official games: we designed it ourselves. The real test is ECHO-4.5's
  final exam, with 16 games we have not touched.
- That ECHO is conscious or a general intelligence. These are specific abilities, measured from the
  outside.

The technical side is in the [ECHO-4.5 documentation](/en/docs/echoai/echo45).
